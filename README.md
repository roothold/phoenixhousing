# Phoenix Housing Group website

Static site for www.phoenixhousinggroup.com. No build step: HTML, CSS and JavaScript only.

- Pages: index, program, housing, about, contact, thank-you, privacy, 404
- Styles: assets/css/style.css · Scripts: assets/js/main.js · Images: assets/img
- Forms post to FormSubmit and deliver to admin@phoenixhousinggroup.com, then redirect to the branded /thank-you page
- Hosted on Vercel (vercel.json enables clean URLs and caching headers)
- Photography via Unsplash (free license)
