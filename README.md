# Phoenix Housing Group website

Static site for www.phoenixhousinggroup.com (The Phoenix Program). No build step: HTML, CSS and JavaScript only.

- Pages: index, program, housing, about, intake, schedule, contact, thank-you, privacy, 404
- Styles: assets/css/style.css · Scripts: assets/js/main.js · Images: assets/img
- Forms send in the background to FormSubmit (admin@phoenixhousinggroup.com) and land on the branded /thank-you page
- Hosted on Vercel (vercel.json enables clean URLs and caching headers)
- Photography via Unsplash (free license)
